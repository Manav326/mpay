# Customer Care

## Chat

Customer Care chat is shared with the mPay support team. An AI reply is only generated when the Admin-controlled Customer Care AI setting is enabled and the AI provider is configured.

## Human escalation

The customer can continue using the same support conversation. Human support staff can reply in the same conversation and can handle callback escalation.

## Callback

A voice callback is a separate support action. A customer callback request does not itself start an audio call; support staff explicitly initiate the call.
